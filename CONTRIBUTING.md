# Contributing to Polai Frontend

Thank you for your interest in contributing to **Polai**! This repository is the Next.js web application for trading and viewing decentralized prediction markets on Stellar.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v20+)
- [npm](https://www.npmjs.com/)

### Local Development & Testing
```bash
# Clone the repository
git clone https://github.com/polaiLabs/frontend.git
cd frontend

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Drips Wave Contributions
We welcome contributions through the **Drips Wave** program!

- Check the issues board for `Stellar Wave` or `good first issue` tasks.
- Keep UI components accessible, responsive, and styled with Tailwind CSS.
- Ensure the production build passes (`npm run build`) before submitting a Pull Request.
