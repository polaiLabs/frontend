# Polai: Decentralized Prediction Market Frontend

Modern, responsive web client for the **Polai Prediction Market** protocol built with **Next.js**, **Tailwind CSS**, and **Stellar Soroban**.

## Features
- **Live Market Feed & Category Filtering**: Browse active predictions across Crypto, AI/Tech, Gaming, and Governance.
- **Dynamic Probability Bars**: Real-time parimutuel probability calculation and implied odds visualizer.
- **Interactive Trade Slip**: Modal for entering prediction stakes, viewing prospective payouts, and estimating transaction fees.
- **Stellar Wallet Connection**: Pre-configured support for Freighter, Lobstr, xBull, and Albedo.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Blockchain SDK**: `@stellar/stellar-sdk`

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
